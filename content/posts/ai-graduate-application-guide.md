## 先想清楚：保研还是留学

对 AI 方向的学生来说，保研和留学是两条不同的路径，没有绝对优劣，只有匹配度问题。做决定前，先回答三个问题：

1. **你的长期目标**：想进国内大厂、科研院所，还是打算在国外就业、读博？
2. **你的英语水平**：留学需要托福/雅思与 GPA 硬门槛，语言备考周期长
3. **你的科研底子**：两条路都看重科研经历，但国内更认论文与导师关系，国外更认推荐信与研究匹配度

建议在大三上学期结束前定下主方向，避免两线作战分散精力。

## 保研路径

### 核心要素

- **成绩排名**：大多数顶尖项目要求前 10%~20%，是硬门槛
- **科研经历**：一段深度参与的研究，优于三份浅尝辄止的实习
- **论文**：CCF 推荐会议/期刊为佳，但"一段完整的科研训练"比"挂名论文"更重要
- **导师推荐**：夏令营前主动联系意向导师，邮件要有实质内容

### 时间线

| 时间 | 事项 |
| --- | --- |
| 大三上 | 确定方向，进入课题组，确定研究选题 |
| 大三寒假 | 完成第一轮文献调研，形成初步 idea |
| 大三下 | 推进科研，准备夏令营材料（简历、个人陈述、成绩单） |
| 4-6 月 | 投递夏令营，联系导师，准备面试 |
| 7-8 月 | 参加夏令营、预推免面试 |
| 9 月 | 国家推免系统填报，锁定 offer |

### 准备建议

- 简历突出**研究问题、你的贡献、量化结果**，避免罗列课程
- 面试重点准备：你的研究讲清楚（Motivation → 方法 → 实验 → 结论）
- 联系导师时附上"我读过你的某篇论文，关于某问题我的想法是……"，而非群发模板

## 留学路径

### 核心要素

- **GPA**：目标院校不同门槛不同，名校热门方向普遍要求 3.5+/4.0 或 85+
- **语言成绩**：托福 100+ / 雅思 7.0+ 是主流目标，越早考越好
- **研究经历**：与申请方向匹配的研究经历是决定性因素
- **推荐信**：2-3 封，来自真实了解你科研工作的老师
- **文书**：个人陈述要讲清"为什么是你 + 为什么是这个方向"

### 时间线

| 时间 | 事项 |
| --- | --- |
| 大二~大三上 | 保持 GPA，备考语言，尽早进入实验室 |
| 大三寒假 | 完成首考托福/雅思，确定申请方向与国家 |
| 大三下 | 推进研究，参加暑期科研（可争取海外暑研） |
| 6-8 月 | 准备文书初稿，联系推荐人 |
| 9-11 月 | 网申高峰期，提交材料 |
| 次年 1-4 月 | 面试、等待结果，对比 offer |

### 准备建议

- 海外暑研是留学申请的"捷径"，能同时拿到研究经历与强推荐信
- 推荐信宁缺毋滥：一封来自深度合作老师的强推，胜过三封客套信
- 选校梯度要合理：冲刺、匹配、保底三档各配 3-4 所

## 两条路径共同的加分项

无论走哪条路，以下经历都能显著提升申请竞争力：

1. **一个完整可复现的科研项目**：代码开源、可复现实验
2. **AI 竞赛成绩**：Kaggle、顶会赛题的成绩证明工程与团队能力
3. **开源贡献**：给主流框架或工具库提过有效 PR，是极强的差异化信号

## 现在就可以开始的三件事

1. **盘点现状**：写下你的 GPA、科研经历、语言成绩现状，对照上面清单找差距
2. **确定一个锚点**：明确保研还是留学，避免两线作战
3. **开始一段研究**：立刻联系导师或加入实验室，完整的研究经历需要时间积累

升学准备的本质是**用时间换匹配度**。信息差可以用清单弥补，但扎实的科研训练和语言积累，只能靠提前开始。
