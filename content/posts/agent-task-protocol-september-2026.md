## 协议比角色重要

GOAI Agent Infra 赛道把多 Agent 分工、可复用和可观测写进赛题方向。复赛材料已于 9 月 3 日截止，9 月 4 日评审启动。无论是否参赛，这三项都是生产系统过安全评审的同一套语言。

任务协议是一份给人和给机器看的短文档，至少包含：允许调用的工具名单、每类工具的参数约束、超时、重试次数、何时交给人类。角色提示词可以变，协议不应在运行时被 Agent 自己改写。

## 最小实现

- 工具白名单放在配置文件，不放在提示词里。
- 每次调用写审计日志：谁、调用了什么、入参摘要、结果摘要、耗时。
- 超时或连续失败后进入只读模式，等待人工确认。

这三件事做完，系统才谈得上可审计。再增加子 Agent 之前，先让这一份协议在单 Agent 上跑稳。
