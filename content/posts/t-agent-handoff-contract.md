## 交接需要结构化信息

Agent 之间传递自然语言摘要时，容易遗漏约束和工具结果。交接对象至少包含任务目标、输入来源、已验证事实、执行过的动作、待处理风险和下一步负责人。

## 每次交接都能复核

让接收方先确认关键信息，再执行下一步工具调用。工具结果保存为可追溯引用，高风险动作记录审批人和时间。出现异常时，协调 Agent 可以根据交接记录选择重试、回滚或转人工。

从两个角色的简单流程开始，例如“资料检索 Agent”交给“报告生成 Agent”。稳定后再加入评审或执行角色，多 Agent 架构会更容易维护。
