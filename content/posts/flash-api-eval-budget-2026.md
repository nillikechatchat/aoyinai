## 额度要花在能复跑的地方

开学季云厂商和模型平台仍在发放免费额度与每日重置额度。最常见的浪费是：用旗舰模型反复生成演示文案，评测集却还没建。更划算的拆法是 **Flash 档承担回归，旗舰档只跑关键步骤**。

Gemini 3.8 Flash 公开定价为每百万 token 输入 0.75 美元、输出 3.75 美元，适合把 30 至 80 条评估集每天跑一遍。旗舰档留给需要长程推理或严格对齐的少数请求。

> 价格对照：[Morph LLM API 汇总](https://www.morphllm.com/llm-api)（核验 2026-09-02）。各平台免费额度以官网实时规则为准。

## 一份可执行的额度分配

- 60%：评测回归与失败样本重跑
- 25%：模型横向对比（同一评测集换模型）
- 15%：演示和探索，设每日上限

生产环境另算。免费档通常有 RPM / TPM 限制，并发高的场景要先做压力验证，不要把免费密钥直接接到用户流量上。
