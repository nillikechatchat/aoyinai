## 写权限是产品，不是默认能力

给 Agent 邮箱发送、工单关闭、代码合并这类写权限，等于把不可逆操作交给一条不确定的推理链。上线顺序应反过来：先只读检索和草稿生成，人工确认后再执行；每类写操作必须有对应的逆向动作或补偿事务。

没有逆向操作的能力，就不要进工具名单。删库、不可撤回的对外发送、直接 push 到主分支，都属于这一类。

## 工程检查单

- 每条写操作日志可按任务 ID 回放。
- 失败后状态机停在「待确认」，而不是「已完成」。
- 演示环境与生产凭证隔离，演示允许模拟成功。

企业采购已经把回滚当成必选项。课程项目和黑客松 Demo 提前按这个标准做，作品集里的「可审计」才不是空话。
