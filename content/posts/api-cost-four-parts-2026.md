## 单价下降，账单未必下降

token 均价下跌后，很多人以为「换更便宜的模型就省钱」。Agent 场景里，输出和工具调用才是大头：一次任务可能包含多轮思考、几次检索、一次代码执行和两次重试。只比较输入单价，会得出错误的选型结论。

## 怎么记

每次任务写四列：输入 token 费用、输出 token 费用、工具 / 检索费用、因失败产生的重试费用。周报只看「完成一次成功任务的全成本」和完成率。完成率低的模型，哪怕单价更低，全成本也会更高。

缓存命中定价（部分国产 API 已提供）适合长系统提示词。把稳定的系统提示放进可缓存前缀，比把整段对话每次重传更省。具体折扣以厂商定价页为准。
